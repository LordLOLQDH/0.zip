Worum geht's?0.zip ist ein verschachteltes ZIP-Archiv. Jede Ebene enthält die nächste. Ganz unten warten Textdateien, die ausschließlich aus dem Zeichen 0 bestehen.
01 / Der Aufbau

Immer eine Ebene tiefer.

Das Prinzip ist bewusst einfach: Archive enthalten weitere Archive. Entpackt man sich Schritt für Schritt hindurch, erreicht man schließlich die unterste Ebene. Dort besteht der Inhalt aus schlichten Textdateien voller Nullen. Genau daher kommt der Name.

02 / Der Name

Warum eine Null?

Weil die unterste Ebene aus Textdateien besteht, deren Inhalt nur aus Nullen besteht. Keine komplizierte Geschichte. Eine kleine Idee, konsequent verschachtelt.
